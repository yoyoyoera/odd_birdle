## 4. 찾은 것과 아직 의심되는 곳

**찾은 것 (고침)**
1. 실제 Y8 SDK는 Y8 밖에서 `showAd` 후 "Ad is initializing, waiting..."만 찍고 콜백을 하나도 안 부른다. 1.0.1은 3번째 경기 이후 재경기 클릭이 **20초 동안 무반응**(`giveUp` 20000). Y8 안에서도 같은 일이 생기면 반려 원인일 수 있다. 3초로 줄임.
2. (1.0.1엔 없고 이후 main에 생긴 회귀) 진 뒤 밖을 클릭하고 돌아오면 PAUSED 안내가 결과 화면을 덮고 첫 클릭을 먹었다. 고침.

**아직 확인 못 함 — 다음에 볼 곳**
1. **진 순간에만 도는 코드가 Y8 iframe에서 예외를 던져 `client.js` `frame()` 루프가 죽는 경우.** `frame()` 안 어디서든 예외가 나면 `requestAnimationFrame(frame)`에 도달하지 못해 화면 전체가 영구 정지한다. 후보: `sound-cues.js`의 'lose' 큐 → `sound.js` `play()`(오디오 컨텍스트 상태), `crowd.js`(finished 시 applauseBig·cheer), `confetti.js`, `juice.js`. 헤드리스 테스트는 `--autoplay-policy=no-user-gesture-required --mute-audio`로 돌려 오디오 경로가 실제와 다를 수 있다. 안전장치로 `frame()` 본문을 try/catch로 감싸 예외가 나도 다음 프레임을 예약하게 하는 것을 권한다.
2. Y8 실제 페이지에서 광고가 **실제로 뜨는** 경우(beforeAd 후 afterAd/adBreakDone 순서), Y8 로그인(`autoLogin: true`)·동의(CMP) 창이 뜨는 경우.
3. "Adapts to any size" 설정에서 Y8이 iframe 크기를 바꾸거나 전체화면으로 전환할 때.

## 5. 테스트 도구 `tools/y8-lab`

```
cd tools/y8-lab && npm i
node ../../scripts/build-portal.mjs y8      # 최신 Y8 빌드(portal/y8)
node prepare.mjs                             # games/ 에 ready(1.0.1)·new·*-local 준비
node static.mjs &                            # 8770 호스트, 8771 게임(서로 다른 origin)
node relay.mjs &                             # 온라인 테스트용 로컬 matchmaker(8772)
node flow.mjs ready cpu none                 # <ready|new> <cpu|quick> <none|blur|blurhover> [mobile]
node online.mjs new-local                    # 두 명 온라인
node ad.mjs ready                            # 실제 Y8 SDK 광고 경로
node layout.mjs                              # iframe 크기별 버튼 위치
```

- Chrome 경로는 기본 `/Applications/Google Chrome.app/...`, 다르면 `CHROME=` 환경변수.
- 한 판 지는 데 1~2분 걸린다. 동시에 8개까지는 `static.mjs`로 문제없었다(파이썬 http.server는 동시 요청에서 연결을 끊어 오탐을 냈다).
- 결과 줄 끝의 `OK restarted` / `STUCK after restart click` 으로 판정. 페이지 오류는 `page errors:` 줄에 모인다. 404 두 개는 SDK가 찾는 파일이라 무시해도 된다.

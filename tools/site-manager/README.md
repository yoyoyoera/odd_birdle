# Odd Birdle 사이트 관리 봇

Node.js 22 이상. 외부 패키지 설치 없이 실행한다.

```sh
node tools/site-manager/bot.mjs
node --test tests/site-manager.test.js
```

`output/latest.md`에 최신 한국어 보고서, `output/state.json`에 이전 수집값, `output/drafts/`에 영어 개발일지 초안이 생긴다. 실행한 시간별 보고서도 보관한다. 출력은 개인 지표를 포함할 수 있어 git에서 제외한다. 초기 보고서는 API 키 없이도 공개 페이지·검색 노출을 확인한다.

## 자동으로 하는 일

- 웹·itch 공개 HTML 접속과 제목 확인. 게임 iframe, 광고, 매칭은 실행하지 않는다.
- itch 정확한 게임 주소가 제목 검색/지정 목록의 응답에 있는지 확인. 차단·네트워크 실패는 확인 불가로 남긴다. 목록 첫 페이지에서 빠졌다고 미색인으로 단정하지 않는다.
- itch 공식 API의 이 게임 누적 조회·다운로드·구매 건수 및 직전 정상 수집 대비 증가량. 다른 게임·수익 상세는 저장하지 않는다.
- 기존 Cloudflare Analytics Engine의 최근 7일 이벤트 집계. 고유 방문자나 전체 플랫폼 수치로 표현하지 않는다.
- 최근 정식 GitHub 릴리스 최대 20건의 릴리스 노트를 영어 개발일지 초안으로 정리. 릴리스 ID와 본문 해시로 중복 생성을 막고 사람이 수정한 초안을 보존한다. 정식 릴리스가 없으면 업데이트를 지어내지 않는다. GitHub 릴리스만으로 itch 배포를 확정할 수 없어 초안에 확인 문구를 넣는다.

## 연결

기존 환경변수만 읽는다. `.env`를 자동 탐색하거나 브라우저 쿠키·로그인 토큰을 추출하지 않는다. 키를 채팅, 코드, 커밋에 넣지 않는다.

| 환경변수 | 용도 | 없을 때 |
|---|---|---|
| `ITCH_API_KEY` | `https://api.itch.io/profile/games` Bearer 인증 | itch 지표는 연결 전 |
| `CLOUDFLARE_ACCOUNT_ID` | Analytics Engine 계정 | 게임 내 지표는 연결 전 |
| `CLOUDFLARE_API_TOKEN` | Account Analytics: Read 권한 | 게임 내 지표는 연결 전 |
| `GITHUB_TOKEN` | 공개 GitHub API 요청 한도 확보, 선택 | 익명 조회 |

환경 파일을 별도로 안전하게 보관했다면 Node의 `--env-file=/절대/경로/개인.env` 옵션을 쓸 수 있다. 봇 출력 디렉터리, 환경 파일, 키는 공개 배포에 포함하지 않는다. 일반 itch 사용자 API 키는 문서상 scope 제한이 없으므로 계정용 비밀값으로 관리한다.

## 반복 실행

하루 한 번 정도면 충분하다. 같은 출력 디렉터리를 사용하면 직전 수집과 비교하고 6시간 이내 재요청은 캐시로 처리한다. `--force`는 실제 재검증이 필요할 때만 쓴다. `--out /절대/경로`로 결과 위치를 바꿀 수 있다. 동시 실행은 잠금으로 차단한다. 비정상 종료 후 `.lock`이 남으면 실행 프로세스가 없는지 확인한 뒤 해당 잠금 폴더를 제거한다.

보고서나 초안 작성 실패는 종료 코드 1로 알린다. 개별 사이트 차단·API 미연결은 전체 작업을 중단하지 않고 보고서에 남긴다. HTML 확인 자체는 플랫폼 조회에 잡힐 수 있다. 자동으로 게임을 플레이하거나 반복 새로고침하여 노출을 올리는 기능은 없다.

## 게시와 심사

itch 공식 서버 API에 개발일지 작성·게시 엔드포인트가 문서화돼 있지 않다. 현재 버전은 **초안 생성까지** 자동화한다. 공개 글 게시나 신규 로그인은 별도 브라우저 작업이 필요하다. 아래 링크에서 초안을 검토하고 게시할 수 있다.

- itch 게임 편집: https://itch.io/game/edit/5350750
- 공개 게임: https://studiyo21.itch.io/odd-birdle
- API 문서: https://itch.io/docs/api/serverside

`config.json`의 Y8·GamePix 심사 중/GD 대기 상태는 2026-11-17 사용자 확인 기록이다. 봇은 심사 통과를 추정하거나 제출본을 교체하지 않는다. 새 공개 URL이나 심사 결과를 받으면 이 설정을 갱신한다. CrazyGames·Newgrounds 반려 건은 자동 재제출하지 않는다.

이 봇은 운영 현황 정리와 글 준비를 줄여 준다. 추천란 선정이나 검색 순위를 올려 주는 봇이 아니다. 다섯 플랫폼의 빌드 일괄 배포는 별도 기능이며 구현하지 않았다.
